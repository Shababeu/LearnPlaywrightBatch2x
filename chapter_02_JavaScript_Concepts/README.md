# Chapter 02: JavaScript Concepts

This chapter covers important JavaScript concepts that help learners write better Playwright and automation scripts.

The topics in this chapter are explained in simple words, with small examples that are easy to read and practice.

## Chapter Purpose

The goal of this chapter is to help learners understand how JavaScript naming, variables, and comments work before moving into more advanced automation code.

## Chapter Files

| File | Topic |
| --- | --- |
| `05_Variable.js` | Variable reassignment without `let` or `const` |
| `06_Identifiers_Rules.js` | Valid and invalid identifier naming rules |
| `07_Identifiers_Case.js` | Naming conventions such as camelCase, PascalCase, snake_case, UPPER_SNAKE_CASE, kebab-case, and Hungarian notation |
| `08_Comments_Shortcut.js` | Single-line and multi-line comments, plus useful VS Code and Windows shortcuts |

## Topics Covered

- Variable reassignment
- Identifier naming rules
- Common naming conventions in JavaScript
- Single-line comments
- Multi-line comments
- Useful keyboard shortcuts for writing and editing code

## Learning Outcome

After completing this chapter, a learner should be able to:
- Understand how variable assignment works
- Identify valid and invalid variable names
- Follow common naming styles used in JavaScript projects
- Use comments correctly to explain code
- Use shortcuts in VS Code to work faster

## Notes

- These lesson files are planned for this chapter
